# Monetize GTA 6

Página estática do pack de vídeos, preparada para publicação no GitHub Pages.

- `index.html`: página principal com o layout existente para celular e computador.
- `video-*.mp4`: 43 vídeos de demonstração, incluídos no próprio repositório.
- Apresentação principal: player do Vimeo incorporado.
- Autoplay dos exemplos sem som; toque no vídeo para ativar o áudio.
- Checkout e contatos permanecem pendentes de configuração em `CONFIGURACAO.md`.

## GitHub Pages

Publicar a branch `main`, pasta `/(root)`. O arquivo `.nojekyll` permite servir o site diretamente.

## Conteúdo

Os 43 arquivos MP4 são os exemplos presentes na página fornecida. O acervo comercial completo de 2.600 vídeos não foi fornecido e não está incluído neste repositório.
